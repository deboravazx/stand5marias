# Stand 5 Marias — Website Project

A vehicle dealership website project featuring vehicle collections, brand-specific content, layout exercises, and visual assets.

> **Project status:** Portfolio/documentation review. This repository contains website assets and exercises; a working deployment and setup instructions have not yet been verified.

## Repository contents

- `Carros_Imagens/` — vehicle imagery
- `Ford/`, `Lexus/`, `Mercedes/`, `Marcas/`, `Outras/` — brand and category resources
- `Galeria_Flex.txt` and `Galeria_Grid.txt` — layout exercises/examples
- `TextoStand.txt` and `TextoServiços.txt` — draft content
- `ExemploStand.pdf` — project reference document

## Goals

This project showcases practice in designing and organizing web content for a vehicle dealership. The current repository is preserved as learning material.
